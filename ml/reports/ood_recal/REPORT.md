# Recalibration of the unfamiliar-EEG detector (sedation_v2)

Generated by `nbml.ood_recal` and `nbml.ood_deploy`; numbers are from `results.json` in this folder.

## Problem
The detector that warns "this EEG looks unlike what the model was trained on" was fitted on the two propofol laboratories only.
On ordinary resting EEG from other sources it fired far too often, so it carried little information.

| Source (never used to fit it) | Recordings | Called unfamiliar by the old detector |
|---|---|---|
| Routine clinical EEG (ds004504, 88 people) | 88 | 33.0 % |
| EEGMMIDB resting EEG (awake people, other device) | 95 | 33.7 % |
| Figshare prolonged-DoC EEG (no labels) | 96 | 46.9 % |

(The earlier "100 %" figure belonged to the first model, v1, with 74 features. This table is for v2.)

## Method (decided before looking at results)
1. Fit the detector on four sources instead of two: Cambridge + Oslo propofol, routine clinical EEG, EEGMMIDB resting EEG.
2. Choose the percentile (99 / 99.5 / 99.9) by leave-one-dataset-out: fit on three sources, test on the fourth, which the detector never saw.
   Rule: maximise detection of corrupted EEG minus false flags on real unseen sources.
3. The Figshare set is never used for fitting or choosing: it is the external check.
4. Detection power uses corruptions of real EEG (40 EEGMMIDB eyes-closed recordings): muscle noise, white noise, 3 dead channels,
   shuffled electrode order, one very noisy electrode. The detector for this test excludes EEGMMIDB.
5. A feature vector that is not finite (NaN or infinity, which a dead channel can cause) is always flagged.

Epoch counts in the pool: Cambridge 3,082, Oslo 512, routine clinical 6,260, EEGMMIDB 361 (95 of 218 runs kept at least one epoch under the fixed
200 microvolt rejection rule), Figshare 1,152.

## Results
| Percentile | False flags on an unseen source (mean of 4) | Corruption detection (mean of 5) |
|---|---|---|
| 99.0 | 11.3 % | 78 % |
| 99.5 | 8.9 % | 77 % |
| **99.9 (chosen)** | **2.4 %** | **71 %** |

Chosen detector, false flags per held-out source: Cambridge 0 %, Oslo 8.5 %, routine clinical 1.1 %, EEGMMIDB 0 %.
Detection at 99.9: muscle noise 100 %, white noise 100 %, three dead channels 97.5 %, one noisy electrode 57.5 %, **shuffled electrode order 0 %**.
Clean recordings flagged: 0 %.

External check (Figshare, never used): **1 of 96 recordings called unfamiliar** (was 46.9 %).

Whole frozen v2 model on sources it never trained on:
- EEGMMIDB (awake healthy people, 95 recordings): 78 awake-like, 0 sedated-like, 17 uncertain, 0 unfamiliar.
- Figshare (no labels, 96 recordings): 47 awake-like, 4 sedated-like, 45 uncertain, 1 unfamiliar. Not evidence about the patients.

## Honest limits
- The detector is now quiet on ordinary resting EEG and loud on noise and dead channels, but it does NOT catch shuffled electrode order,
  because the features are region averages. The doctor must check the montage.
- Oslo is the least well covered source (8.5 % false flags when unseen); a new laboratory can still be flagged.
- A quiet detector means "looks like EEG we have seen", not "the answer is right". It does not make the model valid for patients.
- The percentile was chosen on four sources; the Figshare check was not used for choosing.
- Only the detector inside the v2 bundle changed (new SHA-256 in the model card). The classifier, calibration and conformal threshold are unchanged.
